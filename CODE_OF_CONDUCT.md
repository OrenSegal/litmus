# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code and ideas rather than
people, and keep discussion on topic. Harassment, personal attacks and
discriminatory language are not acceptable in issues, pull requests, reviews or
any other project space.

## Reporting

Report unacceptable behavior to the maintainer, Oren Segal, through a private
GitHub security advisory on this repository or by contacting the maintainer
directly on GitHub (@OrenSegal). Reports are handled confidentially.

## Enforcement

The maintainer may edit or remove comments, commits, issues and other
contributions that break this code, and may block contributors who do so
repeatedly or seriously, following the Contributor Covenant's enforcement
guidelines.
